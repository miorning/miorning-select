## 少切几次窗口，专心选片

生成了好多条视频，来回切着看，很容易忘记上一条到底哪里更好。喵咛选片台把网页上或本机的素材放在同一个面板里，方便一起看、一起听、调整顺序，再挑出真正能用的片段。

- **图片、视频一起比**：网页点选、本地文件选择或拖拽导入，最多 16 条素材同屏；支持排序、盲选、屏蔽和删除。
- **图片老实待着**：播放时图片与它的时间条不动，GIF 等动图也固定显示载入时的一帧。原文件照常完整保存，图片不参与视频剪辑。
- **两秒就能选一段**：选初始帧，设置时长，默认 2 秒；也能一键取末尾 2 秒，或从终点往前截。确认后立即新增到插件片段画布，最多 64 段同屏。
- **把素材带回当前网页**：完整图片、视频和支持导出的片段均可交给当前页面的新增上传、导入或附件入口；每次使用独立文件名，不替换已有节点，不自动发送聊天消息。
- **跨网页继续选**：素材、配乐、片段与排列保存在当前浏览器的扩展本机库。切换网页或重启浏览器后仍可恢复，也可以单独删除或清空。
- **配乐从想要的地方开始**：设置原曲起止点与时间线上延后，支持试听；「剪辑 / 下载」的全片预览遵循所选配乐或各片段原声。
- **小猫随时在边上**：普通网页默认显示猫头，悬停展开、移开收回；安装不弹欢迎页。日夜模式免费，17 项应用快捷键可在右上角「⋯」中调整。

## 安装到 Chrome / Edge

1. 从 [Releases](https://github.com/miorning/miorning-select/releases/latest) 的 **Assets** 下载 **`MiorningSelect-v0.6.0.zip`**。GitHub 自动生成的 `Source code (zip)` 是仓库快照，也包含源码；这里推荐整理好的安装包。
2. 完整解压到准备长期保留的目录。
3. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启「开发者模式 / 开发人员模式」。
4. 点击「加载已解压的扩展程序 / 加载解压缩的扩展」，选择包内的 **`extension` 文件夹**；这一层应直接包含 `manifest.json`。
5. 刷新已经打开的普通网页，点击页面边缘的猫头打开菜单。

无需编译、安装依赖、账户登录或常驻服务器。加载后不要删除或移动该目录。本项目以 GitHub 安装包发布，**未上架浏览器扩展商店**。

本轮在真实 Chrome Manifest V3 扩展环境中验证；Edge 提供相同的解压加载方式，但不表示本版本已经完成独立 Edge 全量验收。

## 第一次使用

1. 默认按 **`Alt + Shift + V`** 开始网页点选，点击图片或视频加入，再按 **`Esc`** 完成；也可以从猫头菜单进入。
2. 默认按 **`Alt + Shift + M`** 打开或收起工作台。点击「本地素材」或直接拖入文件，可以加入本机图片与视频。
3. 拖标题改变顺序，按播放进行对比；图片保持静止。图片的截取、原声与精调按钮留在原位置并置灰。
4. 视频卡片点「截取」，选范围后确认，片段立即出现在插件画布；需要时再交回当前平台。
5. 右上角 **「⋯」** 可以设置快捷键、查看本机素材与缓存、打开帮助。应用快捷键与浏览器级扩展命令分开设置。

## 更新时保留素材

**不要先卸载旧扩展。** 先备份原安装目录，再用新版 `extension` 内文件覆盖原目录，在扩展管理页面重新加载原扩展，最后刷新网页。

本机库按浏览器资料与扩展 ID 隔离；换目录、换浏览器或换资料可能得到新的扩展身份，不会自动带走原缓存。备份安装目录仅保存程序文件，**不等于备份媒体缓存**。卸载扩展或清除扩展数据会删除缓存，请自行保留重要原文件。

新版会迁移当前或最近一份旧版项目，其余旧记录可在缓存管理中追加。超过 16 条图片/视频、1 条配乐或 64 个片段时会提示，旧记录仍保留。

## 素材保存在哪里

文件与编辑状态保存在**当前浏览器资料、当前扩展 ID 的 IndexedDB**，数据库名为 `miorning-select-persistence-v1`。这是浏览器管理的本机数据库，不是普通图片或 MP4 下载文件夹，不自动跨设备同步。

本地导入会缓存原文件；在线选入会尝试读取并缓存原文件，**单文件上限 250 MiB**。无法读取、需要额外授权、受 DRM 保护或过大的在线源会标记「仅链接 · 未缓存」。插件不会以降低清晰度换取缓存成功；未缓存链接失效后，需要重新选入或导入原文件。

「本机素材与缓存」显示文件数、媒体字节数及未完成缓存。单独删除素材会释放对应文件和片段；「清空全部素材与缓存」确认后清理共享素材库、配乐、片段和旧记录，保留主题与快捷键。普通扩展不能直接打开任意系统文件夹，界面提供浏览器资料路径入口。

## 原画质范围与平台边界

| 操作 | 行为与限制 |
| --- | --- |
| 完整图片 / 视频导入画布 | 交出原文件字节，不重新压缩。目标网页需有可识别的新增入口，并接受该文件格式。 |
| 快速单段截取 | 当前原编码导出支持 **H.264 / AVC MP4**；复制源压缩包，保持分辨率与帧率。按源帧边界取整，实际边界可能相差一个源帧。其他编码或复杂编辑列表会明确失败。 |
| 多段「剪辑 / 下载」与混音 | **会重新编码**，不属于单段原编码导出的保证范围。 |
| 图片对比 | PNG、JPEG、WebP、GIF、AVIF、BMP、SVG 等取决于浏览器能否解码；按原尺寸解码并保持比例显示，动图预览静止，导出仍使用原文件。 |
| 网页取源 | 插件只能读取网页实际提供的文件；低清代理无法还原为未提供的高清源。受限页面、跨域 iframe、DRM 或特殊播放器可能无法识别或读取。 |

浏览器设置页和扩展商店等受限页面不会显示猫头。网页布局变化也可能影响点选或回贴。

**「已交给平台」不等于上传、创建节点或保存完成。** 有多个新增入口时由用户选择；没有合适入口时，可先打开平台新增界面再试。插件区分交入与检测到新增媒体，最终结果请在目标平台核对。LibTV、即梦、GPT 等登录后生产页面尚未逐一验收；本机画布和聊天示例通过不代表所有平台兼容。目标平台收到文件后是否再次转码，由平台决定。

## 权限、隐私与验证

扩展使用 `activeTab`、`scripting`、`storage`、`unlimitedStorage` 及 HTTP/HTTPS 站点访问权限，用于默认猫头、用户点选、原文件读取和本机素材库。只缓存用户选入的素材，没有自建上传服务或遥测接口；主动「导入画布」会将所选文件交给目标网页。详见 [隐私说明](docs/PRIVACY.md)。

v0.6.0 在独立 Chrome 资料中通过图片比较、网页点选、原文件缓存与回贴检查，并回归视频库、配乐预览、快捷键与平台新增流程。缓存 / 回贴的图片文件经过 SHA-256 核对；16 条混合素材布局在 1440×900 和 1000×720 验证。测试使用本地示例，不代表所有网站或硬件已验收。
